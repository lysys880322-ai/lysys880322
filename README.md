# 유튜브 다국어 번역 등록기

한국어/영어로 올린 유튜브 영상의 제목·설명을 AI로 번역해서, YouTube Studio의 "다국어 제목·설명"에 자동으로 등록해주는 프로그램입니다.

## 1. 준비물 만들기 (최초 1회)

### 1-1. Google Cloud 프로젝트 + OAuth 클라이언트

1. https://console.cloud.google.com 접속 → 새 프로젝트 생성
2. 왼쪽 메뉴 "API 및 서비스" → "라이브러리"에서 **YouTube Data API v3** 검색 후 "사용" 클릭
3. "API 및 서비스" → "OAuth 동의 화면"
   - User Type: 외부(External) 선택
   - 앱 이름, 이메일 등 기본 정보만 입력하고 저장 (테스트 모드로 두면 됩니다)
   - "테스트 사용자"에 본인 구글 계정 이메일 추가
4. "API 및 서비스" → "사용자 인증 정보" → "사용자 인증 정보 만들기" → "OAuth 클라이언트 ID"
   - 애플리케이션 유형: **데스크톱 앱** 선택
   - 생성 후 JSON 파일 다운로드
5. 다운로드한 파일 이름을 `client_secret.json`으로 바꿔서 이 프로젝트 폴더(`app.py`가 있는 곳)에 넣기

### 1-2. Gemini API 키

1. https://aistudio.google.com/apikey 접속
2. "Create API key" 클릭 → 키 복사

### 1-3. .env 파일 만들기

`.env.example` 파일을 복사해서 `.env`로 이름을 바꾸고, `GEMINI_API_KEY` 값에 방금 발급받은 키를 붙여넣으세요.

## 2. 설치

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## 3. 실행

```
streamlit run app.py
```

브라우저가 자동으로 열립니다. 처음 "Google로 로그인" 버튼을 누르면 별도 로그인 창이 뜨는데, 본인 유튜브 채널 계정으로 로그인하고 권한을 허용해주세요.

## 4. 사용법

1. 영상 목록 불러오기 → 번역할 영상 체크
2. 번역할 언어 체크 (영어/일본어/스페인어/포르투갈어/힌디어/인도네시아어/독일어/프랑스어)
3. "선택한 영상 번역하기" 클릭 → 표로 결과 확인, 필요하면 직접 수정
4. 이미 등록된 언어는 "기존 번역 있음"으로 표시됩니다. 원치 않으면 해당 줄의 "이 항목 등록" 체크를 해제하세요.
5. "YouTube에 등록"을 눌러야 실제로 반영됩니다 (누르기 전까지는 아무것도 바뀌지 않습니다)

## 주의사항

- `.env`, `client_secret.json`, `token.json` 파일은 절대 Git이나 다른 사람에게 공유하지 마세요.
- 하루 API 사용량 한도가 있어서(YouTube 쪽 쿼터), 영상을 아주 많이 한꺼번에 처리하면 다음날로 넘어갈 수 있습니다.
